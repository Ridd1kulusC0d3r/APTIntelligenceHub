# Segurança

## Escopo
O APT Threat Map é uma página estática: roda inteira no navegador, não tem backend, não coleta dados e não faz requisições em tempo de execução.
O repositório não distribui amostras de malware, binários ou credenciais (há um teste automatizado para isso).

## Reportar uma vulnerabilidade
Use o **Private vulnerability reporting** do GitHub (aba *Security* → *Report a vulnerability*) em vez de uma issue pública.
Inclua passos para reproduzir e o impacto. Exemplos relevantes: execução de script a partir do conteúdo da base (XSS),
link malicioso vindo de uma fonte de dados, ou conteúdo sensível versionado por engano.

## Uso responsável
O material é para defesa: inteligência de ameaças, engenharia de detecção e resposta a incidentes.
As regras e consultas são geradas automaticamente e devem ser validadas em homologação antes de uso em produção.
Atribuições refletem as fontes citadas, não um juízo próprio.

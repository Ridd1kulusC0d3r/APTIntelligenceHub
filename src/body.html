Como usar

• Clique num país para ver quem o ataca, quem é atribuído a ele e o perfil de TTPs contra ele.
• Clique num ponto (grupo) para ver os fluxos dele e abrir o dossiê.
• Arcos = pares origem→alvo agregados dos grupos filtrados (espessura ∝ nº de grupos).
• Cor do ponto = motivação; borda = origem. Use os filtros globais (setor, técnica, ferramenta…) para recortar o cenário.
• Posições: coordenadas APTmap quando válidas; senão espiral ao redor do centróide do país.
